Цель: Превратить текущий многостраничный сайт в универсальный, легковесный Boilerplate. Шаблон оптимизирован для моментальной кастомизации под новые ниши через ИИ без изменения верстки.

1. Изоляция контента (Data-Driven)
Весь текст берется из JSON-файлов в папке src/data/.
ЗАПРЕЩЕНО хардкодить (писать текст напрямую) в React-компонентах.
Для добавления нового языка/ниши ИИ должен только переписать файлы *.json.
2. Вычищенный код
Базовые цвета (Primary, Secondary, Accent) и шрифты вынесены в tailwind.config.ts. Изменение цвета решается правкой 1 строчки.
ЗАПРЕЩЕНЫ inline-стили (атрибут style="...").
Модульность: Header, Footer, карточки услуг разбиты на переиспользуемые компоненты.
Семантика: строгая HTML5 структура (<header>, <main>, <section>, <footer>). Один <h1> на страницу.
3. Оптимизация визуального слоя
Иконки: только lucide-react с stroke="currentColor".
Фоны: только CSS-градиенты, mesh-сетки или легкие SVG-паттерны. Никаких тяжелых JPG/PNG для фонов.
Лимит растра: максимум 1-3 реальные фотографии на весь сайт (аватар специалиста).
4. Специфика Next.js App Router (КРИТИЧЕСКИ ВАЖНО)
Во всех компонентах, использующих framer-motion, useState или onClick, первой строкой в файле должна быть директива "use client";.
SEO-метаданные генерируются через Next.js Metadata API из объекта seo в JSON-файлах.
